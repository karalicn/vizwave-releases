# VizWave releases

**VizWave** turns music, podcasts and voice recordings into videos with moving waveforms,
spectrums and effects, for YouTube, Shorts, Reels and TikTok. An offline Windows app with
a free edition; Pro and Studio are one-time licenses.

- Website, features and pricing: https://x-doo.com/vizwave/
- Download the latest version: https://github.com/karalicn/vizwave-releases/releases/latest/download/VizWave-Setup.exe
- Support: vizwave-support@x-doo.com

This repository only holds the installers (see **Releases**). VizWave's source code is not
public. By installing VizWave you accept its
[license agreement](https://x-doo.com/vizwave/license).

## Requirements

Windows 10 or 11, 64-bit, with a graphics card that supports DirectX 12 or Vulkan.

## Windows SmartScreen

The installer is not code-signed yet, so Windows may show "Windows protected your PC" the
first time. Choose **More info → Run anyway**. Each release lists the installer's SHA-256
checksum, so you can check that the file is the one published here.

## Third-party software

VizWave includes FFmpeg (LGPL 2.1) and other open-source components; their licenses are
installed with VizWave (the `ffmpeg\licenses` folder and THIRD-PARTY-LICENSES.txt). The
FFmpeg source code is available at https://ffmpeg.org/releases/.
